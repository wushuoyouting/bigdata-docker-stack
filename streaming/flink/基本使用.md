> **本文范围**：集群已装好之后怎么用。讲 Web UI、SQL Client、作业提交、状态查看与常用命令。本文只做独立集群的基本操作，不接 Doris、不写 Paimon。

# Flink 基本使用

> **一句话结论**：浏览器看状态，SQL Client 调试 SQL，flink run 提交 jar 作业。三种入口共用同一个单容器集群。

> **本文解决什么**：装完 Flink 后怎么查状态、怎么执行 SQL、怎么提交作业、怎么取消作业。
>
> **适用谁**：已完成安装教程验收、想动手用集群的用户。
>
> **读完能做什么**：从 Web UI 读作业状态，用 SQL Client 跑查询，提交示例 jar 作业，取消作业并查看日志。

---

## 一、入口总览

| 入口 | 怎么进 | 用来做什么 |
| --- | --- | --- |
| Web UI | 浏览器打开 http://localhost:8081 | 看集群、作业、日志、checkpoint |
| SQL Client | docker exec 进容器 | 调试 SQL、只读查询、提交 SQL 作业 |
| flink 命令 | docker exec 进容器 | 提交 jar 作业、列出作业、取消作业 |
| REST 接口 | curl 调 8081 | 脚本化查询与提交 |

> 所有入口都连到同一个容器。容器名 flink。进入容器的固定写法是 docker exec -it flink。批量执行用 docker exec -i。

## 二、Web UI 查看

浏览器打开 http://localhost:8081。首页是 Dashboard，显示 TaskManager 数、总槽位、可用槽位、运行中作业数。

| 菜单 | 能看到什么 |
| --- | --- |
| Overview | 集群概况，TM 数与槽位数 |
| Jobs | 作业列表、运行状态、耗时 |
| Job 详情 | 算子图、反压、checkpoint 历史、异常堆栈 |
| Task Managers | TM 列表、日志、线程栈、指标 |

**看作业是否成功**：Jobs 页找作业名。有界源显示 FINISHED 且无异常是成功。无界源显示 RUNNING 且无异常是正常。

**看失败原因**：点开失败作业，进 Exceptions 页。页面显示根因与调用链。这是排查第一类入口。

> Web UI 能上传 jar 提交作业，也能取消作业、触发 savepoint。但它没有 SQL 编辑器。写 SQL 要用 SQL Client 或 Dinky。

## 三、SQL Client 交互模式

> **前提**：容器 flink 处于 Up，overview 返回正常。

```bash
docker exec -it flink /opt/flink/bin/sql-client.sh embedded
```

进入后提示符是 Flink SQL。手敲以下语句做只读验证。

```sql
SHOW CATALOGS;
SELECT 1 AS ok;
EXIT;
```

预期输出：SHOW CATALOGS 列出 default_catalog。SELECT 返回一行，ok 列值为 1。

| 命令 | 作用 |
| --- | --- |
| SHOW CATALOGS; | 列出所有 Catalog |
| SHOW TABLES; | 列出当前库的表 |
| HELP; | 列出支持的语句 |
| SET; | 查看当前配置 |
| EXIT; | 退出客户端 |

> embedded 模式在容器内启动迷你集群。它适合语法调试和只读查询。提交到 8081 集群的作业用 flink run 或 REST 接口。两者不冲突。

## 四、SQL Client 批量模式

把 SQL 从标准输入喂进去，适合脚本化执行。凭据不落盘。

```bash
printf 'SHOW CATALOGS;\nEXIT;\n' \
  | docker exec -i flink /opt/flink/bin/sql-client.sh embedded
```

预期输出：返回 catalog 列表后自动退出。

> SQL Client 会回显执行的 SQL 原文。SQL 里含凭据时，查看输出前先脱敏。本节的示例不含凭据。

## 五、提交 jar 作业

Flink 镜像自带示例 jar。用它验证提交链路。

```bash
docker exec flink /opt/flink/bin/flink run \
  /opt/flink/examples/streaming/TopSpeedWindowing.jar
```

预期输出：打印作业 ID，类似 Job ID 已提交。Web UI 的 Jobs 页出现对应作业。

**列出作业**：

```bash
docker exec flink /opt/flink/bin/flink list
```

**取消作业**：

```bash
docker exec flink /opt/flink/bin/flink cancel <JOB_ID>
```

尖括号占位符在代码块内保持原样。实际执行时把 &lt;JOB_ID&gt; 换成 flink list 输出的作业 ID。

| 命令 | 用途 |
| --- | --- |
| flink run | 提交 jar 作业 |
| flink list | 列出运行中作业 |
| flink cancel | 取消指定作业 |
| flink savepoint | 触发 savepoint |

> 自制作业 jar 要先放进容器。用 docker cp 复制到容器内的 /opt/flink/usrlib/，再按上面的命令提交。生产做法是把 jar 构建进自定义镜像。

## 六、REST 接口

REST 接口适合脚本与监控。所有请求打到宿主机 8081。

```bash
# 集群概况
curl -fsS http://localhost:8081/overview

# 作业列表
curl -fsS http://localhost:8081/jobs/overview

# 指定作业详情
curl -fsS http://localhost:8081/jobs/<JOB_ID>
```

预期输出：overview 返回 JSON，含 taskmanagers 与 slots-total 字段。jobs/overview 返回作业数组。

> 容器内其他服务访问 REST 时写 http://flink:8081。写 localhost:8081 会指向调用方自己，这是最常见的连通性错误。

## 七、查看日志

```bash
# 容器日志
docker logs -f flink --tail 100

# 只筛注册与错误
docker logs flink --tail 300 | grep -iE 'register|error|exception'

# 容器内 Flink 日志文件
docker exec flink sh -c 'ls -lt /opt/flink/log/ | head'
```

| 日志位置 | 内容 |
| --- | --- |
| docker logs | 前台 JobManager 输出 |
| /opt/flink/log/ | start-cluster.sh 启动的 JM 与 TM 日志 |
| Web UI 的 Logs 页 | 选对应 TM 看日志 |

> start-cluster.sh 把 JM 与 TM 作为后台进程启动。它们的日志落在容器内的 /opt/flink/log/，不全部出现在 docker logs 里。排查 TM 问题时要看这个目录。

## 八、常用操作速查

| 想做什么 | 命令或入口 |
| --- | --- |
| 看集群状态 | http://localhost:8081 |
| 看作业列表 | Jobs 菜单或 curl jobs/overview |
| 跑一条 SELECT | docker exec -it flink sql-client.sh embedded |
| 提交示例作业 | docker exec flink flink run 示例 jar 路径 |
| 取消作业 | Web UI 点 Cancel，或 flink cancel |
| 看异常堆栈 | 作业详情的 Exceptions 页 |
| 看 TM 日志 | /opt/flink/log/ 或 Web UI Logs 页 |

## 九、故障速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 页面打不开 | 容器未起或端口不通 | docker ps 与 curl overview |
| SQL Client 起不来 | 容器内存不足 | 查 docker stats，停其他组件 |
| flink run 报找不到 jar | 路径写错或 jar 未复制进容器 | docker exec ls 核对路径 |
| 作业一直 RESTARTING | 代码异常或依赖缺失 | 看 Exceptions 页根因 |
| 看不到 TM 日志 | 只看 docker logs | 去 /opt/flink/log/ 找 tm 日志 |
| 容器内访问 8081 拒绝 | 写了 localhost | 改 http://flink:8081 |
| 取消作业后仍显示 | 状态刷新延迟 | 刷新页面或重新 flink list |

## 十、小结

1. Web UI 看状态，SQL Client 调 SQL，flink 命令提交 jar。三个入口共用一个集群。
2. SELECT 结果回传客户端显示，INSERT 结果写入 Sink。两者行为不同。
3. 有界源 FINISHED 是成功，无界源 RUNNING 才正常。判据是日志无异常。
4. TM 日志在容器内 /opt/flink/log/，不全在 docker logs 里。
5. 容器内互访用别名 flink，不用 localhost。宿主用 localhost。
