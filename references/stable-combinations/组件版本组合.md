# 大数据组件稳定版本组合

本文给出三套稳定版本组合。三套组合覆盖离线数仓、实时数仓与湖仓一体。另给出面向 AI 场景的扩展组件。适用对象是正在选型或升级的大数据平台团队。读完能按场景选定版本，并避开已知兼容陷阱。信息核验日期为 2026-11-24。

## 一、结论

离线数仓以 Hadoop 3.4.3 加 Spark 4.1.4 为基线。实时数仓以 Flink 1.20.5 加 Doris 4.1.4.1 为基线。湖仓一体以 Iceberg 1.12.0 加 Paimon 2.1.0 为基线。AI 场景在这套湖仓基线上补向量、特征与多模态组件。

## 二、离线数仓组合

适用场景包括 T+1 报表与历史回溯。另覆盖大规模批量加工。成本敏感的明细汇总同样适用。

| 层 | 组件 | 版本 | 依据 |
| --- | --- | --- | --- |
| 存储 | Hadoop | 3.4.3 | Hive 4.2.1 声明适配 3.4.1 线 |
| 元数据 | Hive | 4.2.1 | 2026-08-24 发布，修复三个安全漏洞 |
| 计算 | Spark | 4.1.4 | 湖格式连接器支持上限 |
| 调度 | DolphinScheduler | 3.4.3 | 2026-09-08 发布 |
| 服务层 | StarRocks | 4.1.7 | 2026-10-26 发布 |
| 对象存储 | SeaweedFS 或 Garage | 官方当前版 | MinIO 社区版镜像已下架 |

Hadoop 3.5.0 于 2026-04-02 发布。该版本是 3.5 线首个稳定版。Hive 4.2.1 的官方说明写明适配 Hadoop 3.4.1。团队选 3.4.3，避开跨小版本组合风险。

## 三、实时数仓组合

适用场景包括秒级新鲜度与 CDC 入仓。另覆盖实时大屏。风控与运营决策同样适用。

| 层 | 组件 | 版本 | 依据 |
| --- | --- | --- | --- |
| 消息 | Kafka | 4.1.2 | 2026-03-17 稳定补丁版 |
| 计算 | Flink | 1.20.5 | 2026-06-03 发布，连接器覆盖最全 |
| 开发平台 | Dinky | 1.2.5 | 支持 Flink 1.20，漏洞状态需先核实 |
| 服务层 | Doris | 4.1.4.1 | 2026-09-29 发布，4.1 线最新非 RC |
| 调度 | DolphinScheduler | 3.4.3 | 流任务与批任务统一编排 |

Kafka 官网下载页已出现 4.2.0 二进制包。社区页面列出 4.3.0。生产环境取 4.1.2。升级前需逐条核对发行说明。

## 四、湖仓一体组合

适用场景包括流批同源与开放表格式。另覆盖多引擎共享。历史与实时统一查询同样适用。

| 层 | 组件 | 版本 | 依据 |
| --- | --- | --- | --- |
| 对象存储 | SeaweedFS 或 Garage | 官方当前版 | S3 兼容底座 |
| 表格式 | Iceberg | 1.12.0 | 2026-09-29 发布，V3 规范生产可用 |
| 表格式 | Paimon | 2.1.0 | 2026-10-12 发布，主键表实时 upsert |
| 流计算 | Flink | 1.20.5 | Paimon 提供 flink-1.20 连接器 |
| 批计算 | Spark | 4.1.4 | Iceberg、Paimon、Hudi 的公共上限 |
| 查询层 | Doris 或 StarRocks | 4.1.4.1 或 4.1.7 | 两者均支持湖格式 Catalog |
| 编排 | Airflow | 3.4.0 | 2026-11-06 发布，资产分区能力成熟 |

Iceberg 承担多引擎共享与 BI 直读。Paimon 承担 Flink 实时写入与主键更新。Hudi 1.2.1 用于增量拉取场景。该版本不作为默认选项。

## 五、数据底座定位

| 组件 | 核心定位 | 不适合的场景 |
| --- | --- | --- |
| Hadoop 3.4.3 | 离线批处理与元数据底座 | 秒级交互查询 |
| Doris 4.1.4.1 | 实时分析、湖联邦、AI 混合检索 | 超大规模单表高压缩日志 |
| StarRocks 4.1.7 | 极速 OLAP、湖仓查询、标量向量同表 | 强事务写入 |
| ClickHouse 26.8 LTS | 日志、埋点、时序、超高基数单表 | 复杂多表关联与频繁更新 |
| MinIO 社区版 | 已退出主流选择 | 新建生产集群 |

ClickHouse 生产取 LTS 26.8.40.7，发布于 2026-11-18。Stable 26.10.6.18 同日发布。26.10 变更列表含 37 项不兼容改动。StarRocks 不取 4.1.0。该版本容器镜像存在 BE 启动问题。

## 六、调度选型

DolphinScheduler 3.4.3 适合国内团队的可视化 DAG 编排。它内置三十余种任务类型。中文文档与运维资料完整。离线数仓与实时数仓选它。

Airflow 3.4.0 适合代码化定义、Git 管理与 AI 工作流。Airflow 3.4.0 新增有限任务循环。该版本支持任意语言 DAG 编写。Common AI provider 1.0 提供 LLM 与 Agent 任务及人工审批。湖仓与 AI 场景选它。

## 七、AI场景组件

湖仓一体更贴近 AI，原因有三条。多模态数据需要对象存储与开放表格式。训练数据需要版本回溯与可复现。向量、全文与标量过滤需要在同一查询入口完成。

| 层 | 组件 | 版本 | 用途 |
| --- | --- | --- | --- |
| 实时表格式 | Paimon | 2.1.0 | 多模态写入、BLOB、Row Tracking |
| 分析表格式 | Iceberg | 1.12.0 | V3、Variant、geometry、联邦查询 |
| 多模态格式 | Lance | 14.0.3 | 图像与向量随机访问 |
| 向量检索 | Milvus | 3.0.5 | 湖原生向量库与稀疏索引 |
| 特征存储 | Feast | 0.68.0 | 训练与推理特征一致 |
| 混合检索 | Doris | 4.1.4.1 | 标量、全文、向量同表检索 |
| 多模态查询 | StarRocks | 4.1.7 | 一条 SQL 完成圈选与向量检索 |
| 计算 | Flink、Spark | 1.20.5、4.1.4 | 实时写入与批量加工 |
| 编排 | Airflow | 3.4.0 | AI Agent 任务与审批流 |

Doris 4.1 原生支持向量索引与 search 全文检索。StarRocks 4.1 已支持 Paimon 多模态湖仓。该版本把标量索引、向量索引与全文索引放进同一执行框架。Embedding 作为普通表行存储。每行附带源快照 ID 与模型版本。模型更换后可重新生成向量。

向量库不被湖仓替代。Iceberg 与 Paimon 负责事实与特征的版本化底座。Milvus 负责高并发近似最近邻检索。Lance 负责图像、音频与 embedding 的随机读取。

## 八、版本避坑

注意：Doris 4.1.5-rc03 属于候选版。生产环境取 4.1.4.1。

注意：StarRocks 4.1.0 容器镜像存在 BE 启动问题。该版本不进入选型。升级到 4.1 后不可降级到 4.0.6 以下。

注意：Paimon 2.1.0 没有 Flink 2.3 连接器。Flink 2.3 仅与 Iceberg 1.12.0 搭配完整。

注意：ClickHouse 26.10 变更列表含 37 项不兼容改动。生产环境取 LTS 26.8.40.7。

注意：MinIO 官方镜像已从 Docker Hub 下架。新建 compose 文件使用旧镜像会拉取失败。

注意：Dinky 1.2.5 存在第三方漏洞记录。1.2.4 是否在影响范围未从可访问页面确认。升级前需核实影响版本并备份配置。
