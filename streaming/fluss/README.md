# Fluss 学习文档

本文集面向本机环境，讲解 Apache Fluss 1.0.0 的安装、使用与原理。读者读完能独立拉起集群，并用 Flink SQL 完成建表与读写。

三册文档按职责拆分，各自独立成篇。

| 文档 | 回答的问题 |
| --- | --- |
| 安装部署 | 如何在本机拉起一个可用的 Fluss 集群 |
| 基本使用 | 如何用 Flink SQL 建表、写入、消费与点查 |
| 基本原理 | Fluss 的集群角色、表模型与分层存储如何工作 |

## 环境基线

本机已实测的环境如下。文档中的命令均按此环境编写。

| 项 | 实测值 |
| --- | --- |
| 操作系统 | macOS |
| Docker | 29.7.2 |
| Docker Compose | v5.5.0 |
| 已有 Flink | 1.20.5，容器方式运行 |
| 已有对象存储 | MinIO，监听 9000 与 9001 |
| 已有分析引擎 | Superset，监听 8088 |
| 目标目录 | /Users/wenhuadong/docker/streaming/fluss |

## 端口分配

安装前已查询端口占用。分配结果如下。

| 端口 | 用途 | 避让说明 |
| --- | --- | --- |
| 9123 | CoordinatorServer 客户端 | 查询时空闲，供 Flink 连接 |
| 9124 | TabletServer 客户端 | 查询时空闲，映射到容器 9123 |
| 2181 | ZooKeeper 客户端 | 查询时空闲，仅容器网络内使用 |
| 8081 | Flink Web UI | 已被 Flink 占用，不分配 |
| 9000 | MinIO API | 已被占用，不分配 |
| 3306 | MySQL | 已被本机占用，不分配 |
| 5432 | PostgreSQL | 已被本机占用，不分配 |

## 版本说明

本文基于 Fluss 1.0.0。该版本于 2026 年 9 月发布，是稳定的正式版本。Flink 连接器选用 fluss-flink-1.20-1.0.0，与本机 Flink 1.20.5 兼容。

ZooKeeper 选用 3.9.2。官方 Docker 示例采用该版本。
