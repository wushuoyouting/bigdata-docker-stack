## 二、部署形态

> **本机选型**：命令行装在本机虚拟环境。MinerU 官方明确：苹果芯片走本机安装，容器不提供显卡加速。本机是 arm64 芯片，按此形态部署。

| 形态 | 适用 | 本机是否采用 |
| --- | --- | --- |
| 本机虚拟环境 | 苹果芯片、无英伟达显卡 | 采用 |
| 容器部署 | Linux 加英伟达显卡 | 不采用 |

**为什么本机不容器化**：本机 uv 已安装，可按需创建虚拟环境。容器方案在苹果芯片上拿不到显卡加速，还多一层目录映射。命令行直接安装少一层隔离成本。

**容器方案什么时候用**：部署到 Linux 服务器且配英伟达显卡时，按安装教程里的容器章节执行。
