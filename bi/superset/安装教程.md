## 3. 参数与镜像

### 3.1 凭据文件

```bash
set -a
. /Users/wenhuadong/docker/bi/superset/.env
set +a

SUPERSET_HOME=/Users/wenhuadong/docker/bi/superset/home
echo "SUPERSET_TAG=$SUPERSET_TAG  SECRET_KEY已加载=${SUPERSET_SECRET_KEY:+yes}  管理员口令已加载=${SUPERSET_ADMIN_PWD:+yes}"
```

| 变量 | 规则 |
| --- | --- |
| SUPERSET_TAG | 固定明确版本，**不用 latest**（规格书 3.7） |
| SUPERSET_SECRET_KEY | openssl rand -base64 42 生成一次并**长期复用**；不设会每次启动随机，重启后登录态与加密凭据失效 |
| SUPERSET_ADMIN_PWD | 自设、非默认；特殊字符在 .env 里要避免引号冲突 |

> .env 是本机凭据文件：chmod 600、不进任何 git 仓库、不写进文档、不贴进日志（规格书「口令边界」）。文档只出现占位符 &lt;SUPERSET_SECRET_KEY&gt;、&lt;SUPERSET_ADMIN_PWD&gt。装完把实际 tag 与环境变量名（值用占位符）登记到 组件手册（规格书 9.1）。

### 3.2 arm64 镜像

```bash
# 备选 A：优先试原生多平台 / arm 后缀 tag
docker pull "apache/superset:$SUPERSET_TAG-arm"

# 备选 B：没有 arm 版本时用 amd64 模拟（能跑，但启动明显更慢）
docker pull --platform linux/amd64 "apache/superset:$SUPERSET_TAG"

# 判断依据
docker image inspect "apache/superset:$SUPERSET_TAG" --format '{{.Os}}/{{.Architecture}}'
# linux/arm64 → 用原生；linux/amd64 → 走模拟
```

> 模拟模式下首次 db upgrade 好几分钟无输出，**不等于卡死**，先看 docker logs -f superset。

## 4. 启动就绪

```bash
mkdir -p "$SUPERSET_HOME"

docker run -d \
  --name superset \
  --network whd-net \
  --network-alias superset \
  --ip 172.30.0.17 \
  -p 8088:8088 \
  -e SUPERSET_SECRET_KEY="$SUPERSET_SECRET_KEY" \
  -e TALISMAN_ENABLED='False' \
  -v "$SUPERSET_HOME:/app/superset_home" \
  "apache/superset:$SUPERSET_TAG"

# 首次初始化（amd64 模拟时更慢），最多等 5 分钟
for i in $(seq 1 60); do
  out=$(curl -fsS http://localhost:8088/healthcheck 2>/dev/null || true)
  [ "$out" = "OK" ] && { echo "Superset 就绪"; break; }
  echo "第 ${i} 次：还没就绪，等 5s"; sleep 5
done

docker ps --filter name=superset --format '{{.Names}}\t{{.Status}}\t{{.Ports}}'
docker logs --tail 100 superset
```

| 参数 | 为什么 |
| --- | --- |
| --network whd-net --network-alias superset | 规格书 3.4；容器内将来要用别名 doris-fe 连 FE |
| -p 8088:8088 | Web UI；宿主侧可改，容器内部保持 8088 |
| SUPERSET_SECRET_KEY | 会话 / 加密签名密钥，必须固定（规格书 3.6） |
| TALISMAN_ENABLED='False' | 本机 HTTP，不关会被重定向到 HTTPS |
| -v "$SUPERSET_HOME:/app/superset_home" | SQLite 元数据库持久化，删容器不丢 |

| 不通过 | 排查 |
| --- | --- |
| 容器立刻退出 | docker logs superset：exec format error（架构不对）、卷权限 |
| healthcheck 一直非 OK | 模拟模式耐心等；别急着 docker rm |

## 5. 组件初始化

### 5.1 三步初始化

```bash
# 1) 建 / 升级元数据库表结构
docker exec -it superset superset db upgrade

# 2) 建管理员（口令来自本机 .env，不用默认值）
docker exec -it superset superset fab create-admin \
  --username admin \
  --firstname Admin \
  --lastname Admin \
  --email admin@example.local \
  --password "$SUPERSET_ADMIN_PWD"

# 3) 初始化角色与权限
docker exec -it superset superset init
```

> superset fab create-admin 在部分新版本被 flask fab create-admin 取代，报 No such command 时整条换成 docker exec -it superset flask fab create-admin ...，参数不变。管理员已存在时重跑第 2 步会报错，可跳过。

### 5.2 MySQL 驱动

```bash
# 交互式终端用 -it；脚本 / 自动化执行时去掉 -it
docker exec -it superset python -c 'import pymysql; print(pymysql.__version__)' || \
  { docker exec -it superset pip install PyMySQL && docker restart superset; }
```

| 情况 | 处理 |
| --- | --- |
| 输出版本号 | 驱动能力就绪 |
| ModuleNotFoundError | 容器内 pip install PyMySQL 后重启；只是容器内的 Python 包，不算多起组件 |
| 改用镜像自带 mysqlclient | 项目阶段 URI 换成 mysql://，本次不配数据源 |

> **本机实测（2026-11-11）**：apache/superset:4.1.4 镜像未带 PyMySQL；pip install PyMySQL 装到 /app/superset_home/.local/lib/python3.10/site-packages，**在挂载卷里**。因此 docker rm -f superset 重建容器后驱动仍在，只有 rm -rf .../home/* 才会连驱动一起删（届时重装或做自定义镜像固化）。pip show 报 1.2.4，pymysql.__version__ 是包内部版本字符串，不影响 import 判据。重来仍优先 stop/start。

## 6. 逐条验收

```bash
# ① healthcheck
curl -fsS http://localhost:8088/healthcheck; echo

# ② 管理员可登录（只输出结论，不打印 token 或口令）
curl -s -X POST -H 'Content-Type: application/json' \
  -d "{\"username\":\"admin\",\"password\":\"$SUPERSET_ADMIN_PWD\",\"provider\":\"db\"}" \
  http://localhost:8088/api/v1/security/login | grep -q 'access_token' \
  && echo '管理员登录 OK' || echo '管理员登录 FAIL'
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:8088/login/

# ③ 容器内能解析 Doris FE 别名
docker exec superset sh -c 'getent hosts doris-fe'
docker run --rm --network whd-net busybox:1.36 sh -c 'nc -zv doris-fe 9030'

# ④ 驱动能力
docker exec superset python -c 'import pymysql; print("PyMySQL OK")'

# ⑤ stop/start 后密钥与管理员仍有效
docker inspect superset --format '{{range .Config.Env}}{{println .}}{{end}}' \
  | grep -c '^SUPERSET_SECRET_KEY=' | xargs -I{} echo 'SECRET_KEY 环境变量条数: {}'
docker stop superset && docker start superset
curl -fsS http://localhost:8088/healthcheck; echo
curl -s -X POST -H 'Content-Type: application/json' \
  -d "{\"username\":\"admin\",\"password\":\"$SUPERSET_ADMIN_PWD\",\"provider\":\"db\"}" \
  http://localhost:8088/api/v1/security/login | grep -q 'access_token' \
  && echo '重启后管理员登录 OK' || echo '重启后管理员登录 FAIL'

# 网络全貌（规格书第 7 节）
docker network inspect whd-net \
  --format '{{range .Containers}}{{.Name}} | {{.IPv4Address}}{{println}}{{end}}'
```

| # | 通过标准 |
| --- | --- |
| ① | 返回 OK |
| ② | 登录 API 返回 access_token；/login/ 返回 200；浏览器能进首页 |
| ③ | getent hosts doris-fe 解析出 172.30.0.8；nc -zv doris-fe 9030 open |
| ④ | import pymysql 成功 |
| ⑤ | stop/start 后 health 仍 OK、同一口令仍能登录、SECRET_KEY 环境变量条数为 1（值不变） |
| 网络 | 成员新增 superset，IP 在 .5~.199，.2/.3/.4 无漂移 |

> ③ 只证明**网络与端口可达**，不代表已建数据源；规格书 6.3 明确本次不建数据源、不连库。nc 用同网络临时容器是因为 superset 镜像内不一定有 nc。

## 7. 停止、重启与重来

```bash
docker stop superset && docker start superset     # 首选：元数据、管理员、pip 驱动全保留
docker logs -f superset --tail 100

# 完全重来（保留元数据）：重跑第 4 节 docker run
# 初始化只需 db upgrade + init（管理员已存在会跳过）；pip 装的驱动要重装
docker rm -f superset                            # **不加 -v**

# 连元数据库清空（谨慎）：重跑第 3、4、5、6 节
docker rm -f superset
rm -rf /Users/wenhuadong/docker/bi/superset/home/*
```

| 动作 | 数据安全 |
| --- | --- |
| stop / start | 全保留 |
| docker rm -f | home/ 是 bind mount，元数据库与 .local 里的 pip 驱动都保留；只有清空 home/ 才丢 |
| rm -rf .../home/* | 管理员与角色全丢，需重做第 5 步 |
| docker rm -v | **禁止** |

> 验完 docker stop superset。交付常态只保留 Doris + DS + MinIO，BI 按需起。

## 8. 故障速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| exec format error / 容器立刻退出 | arm64 上拉了 amd64 专属镜像 | 选 -arm 或 --platform linux/amd64 |
| 浏览器自动跳 HTTPS | Talisman 强制安全头 | TALISMAN_ENABLED='False' |
| 每次重启要重新登录、凭据失效 | SUPERSET_SECRET_KEY 没固定 | 从 .env 读取同一个值，长期复用 |
| getent hosts doris-fe 失败 | 没接 whd-net | 启动命令带 --network whd-net；FE 由编排已落网 |
| No module named pymysql | 镜像未带驱动 | pip install PyMySQL 后重启 |
| pip install 后驱动又没了 | 清空了 home/ 或换了卷（本机实测驱动落在挂载卷 .local） | 重新 pip install PyMySQL，或做自定义镜像固化 |
| superset fab create-admin 报 No such command | 新版本入口变了 | 换 flask fab create-admin，参数不变 |
| 初始化很久没反应、CPU 高 | amd64 模拟 + 首次 db upgrade | 等几分钟看日志 |
| 挂卷后权限报错 | 本机目录属主与容器内用户不一致 | docker logs superset 看路径 |
| 16G 机器上 BE 被 OOM 杀掉 | 组件全开 | 验完 docker stop superset |
