# MinIO 使用

---

## 0. 使用方式总览

MinIO 本质只有两样东西：**一个 S3 协议服务端（9000）+ 一个 Web 管理台（9001）**。所以「使用方式」不是 N 个并列产品，而是**同一个 S3 API 的不同客户端形态**，差异只有三个维度：走哪个端口、从哪发起、凭据怎么带。

### 0.1 客户端模式

| # | 方式 | 端口 | 发起位置 / endpoint | 凭据 | 适合 |
| --- | --- | --- | --- | --- | --- |
| 1 | Web Console | 9001 | 本机浏览器 | 浏览器登录 | 人工建桶、看状态、建 Key |
| 2 | 宿主机 mc | 9000 | 本机 localhost:9000 | AK/SK | 日常运维、写脚本 |
| 3 | Docker mc 容器 | 9000 | 同网容器 minio:9000 | AK/SK | 不装客户端、验证跨容器 |
| 4 | 通用 S3 CLI | 9000 | 本机 localhost:9000 | AK/SK | 已有 aws cli / s3cmd / rclone 工具链 |
| 5 | SDK 编程接入 | 9000 | 应用进程 | AK/SK | 程序读写对象 |
| 6 | REST API 直连 | 9000 | 任意 | SigV4 / 预签名 / 匿名 | 健康检查、临时下载 |
| 7 | 引擎内嵌 S3 客户端 | 9000 | Doris BE / Flink TM 容器 minio:9000 | AK/SK | Load 入仓、Paimon 写湖 |
| 8 | 挂载成本地文件系统 | 9000 | 本机 FUSE | AK/SK | 老程序只认本地路径（本环境不推荐） |
| + | 预签名 URL / 匿名公开读 | 9000 | 任意 | 无凭据 | 对外临时分享 |

> 第 2、3 类是**同一个 mc 二进制**，差别只在 endpoint 与凭据注入方式；第 4~7 类打的是**同一个 S3 API**，差别主要在各工具的 path-style 参数名，一律用 path-style。

### 0.2 最小命令

**统一前置：加载凭据**（下面 2/4/5 都依赖它）

```bash
set -a; . /Users/wenhuadong/docker/object-storage/minio/.env; set +a
```

- set -a：其后的赋值自动 export 成环境变量。
- . .env：source 出 MINIO_AK / MINIO_SK，命令里只出现变量名，真值不进命令行历史。
- set +a：关掉自动导出，避免污染后续 shell。

**① Web Console** —— 唯一不用显式配 AK/SK 的入口，走 9001

```bash
open http://localhost:9001
```

- open：macOS 用默认浏览器打开。
- 9001 只给浏览器；**任何程序配置都填 9000**。

**② 宿主机 mc（首选）**

```bash
brew install minio/stable/mc
mc alias set lake http://localhost:9000 "$MINIO_AK" "$MINIO_SK"
mc ls lake
```

- brew install minio/stable/mc：官方 tap、arm64 原生，**不经 Docker / 镜像源 / 代理**；Docker Hub 的 minio/mc 已于 2026-09-11 下架，本机又无缓存，所以这条最稳。
- mc alias set 别名 endpoint AK SK：别名写入 ~/.mc/config.json，之后 lake/lakehouse 就代表该桶。
- localhost:9000：宿主机视角。常用命令表 下方。

**③ Docker mc 容器（可选，需自备镜像）**

```bash
MC_IMAGE=your-registry/minio-mc:your-tag      # 换成 docker images | grep mc 查到的实际镜像
docker image inspect "$MC_IMAGE" >/dev/null || { echo "镜像不存在，改用 2.1"; exit 1; }

docker run --rm --network whd-net \
  -v /Users/wenhuadong/docker/object-storage/minio/.env:/tmp/minio.env:ro \
  --entrypoint /bin/sh "$MC_IMAGE" -c '
    set -a; . /tmp/minio.env; set +a
    mc alias set lake http://minio:9000 "$MINIO_AK" "$MINIO_SK" && mc ls lake
  '
```

- --rm 退出即删容器；--network whd-net 才能解析 minio 这个别名。
- -v ...:ro + 容器内 set -a; . ...：**容器内不继承宿主环境变量**，必须挂载再 source，mc 才拿得到凭据。
- minio:9000：容器视角，顺带验证跨容器 DNS。
- 。

**④ 通用 S3 CLI**

```bash
aws configure set default.s3.addressing_style path
AWS_EC2_METADATA_DISABLED=true \
  aws --endpoint-url http://localhost:9000 s3 ls s3://lakehouse
```

- --endpoint-url：把默认 AWS 端点改指 MinIO，**每次都要带**。
- default.s3.addressing_style path：强制 path-style。
- AWS_EC2_METADATA_DISABLED=true：连非 AWS 端点时跳过 IMDS 凭据探测，否则会去连 169.254.169.254 而卡住。
- 。

```ini
# s3cmd：~/.s3cfg
[default]
access_key = ...          # 填 .env 里的 MINIO_AK 真值
secret_key = ...          # 填 .env 里的 MINIO_SK 真值
host_base = localhost:9000
host_bucket = localhost:9000/%(bucket)
use_https = False
signature_v2 = False
```

- host_bucket 写成 localhost:9000/%(bucket) 才是 path-style；写成 %(bucket).localhost:9000 会走 virtual-host，单机 MinIO 解析不了。
- signature_v2 = False 强制 SigV4，MinIO 新版不接受 V2。
- 命令：s3cmd ls s3://lakehouse、s3cmd put /tmp/a.csv s3://lakehouse/ods/user_profile/。

```ini
# rclone：~/.config/rclone/rclone.conf
[minio]
type = s3
provider = Minio
env_auth = false
access_key_id = ...       # 填 .env 里的真值
secret_access_key = ...
endpoint = http://localhost:9000
```

- provider = Minio 自动设好 path-style / region / chunk size，不用手调。
- 命令：rclone lsd minio:lakehouse、rclone copy ./out minio:lakehouse/ods/user_profile/。

**⑤ SDK 编程接入**

```python
import boto3
from botocore.config import Config

s3 = boto3.client(
    "s3",
    endpoint_url="http://localhost:9000",
    aws_access_key_id="<MINIO_AK>",       # 换成真值，或从环境变量读
    aws_secret_access_key="<MINIO_SK>",
    region_name="us-east-1",
    config=Config(s3={"addressing_style": "path"}),
)
s3.upload_file("/tmp/a.csv", "lakehouse", "ods/user_profile/a.csv")
```

- endpoint_url 改指 MinIO；region_name 只为满足 SigV4 签名，MinIO 不校验具体值。
- Config(s3={"addressing_style": "path"}) **必加**，否则拼出 lakehouse.localhost 报 EndpointConnectionError。
- Prefix：S3 没有真目录，ods/user_profile/ 只是对象键前缀。
- 官方 SDK 亦可：pip install minio → Minio("localhost:9000", access_key=..., secret_key=..., secure=False)。
- 。

**⑥ REST API 直连**

```bash
curl -fsS http://localhost:9000/minio/health/live                 # 免鉴权健康接口
URL=$(mc share download --expire=2h lake/lakehouse/ods/a.csv | grep -oE 'https?://[^ ]+')
curl -fsS "$URL" -o /tmp/a.csv
```

- S3 API 要求 **SigV4 签名**，裸 curl 无法直接带鉴权头；带鉴权要先生成预签名 URL（第 2 行）。
- /minio/health/* 是少数免鉴权端点，安装教程.md 的健康检查用的就是它。
- 。

**⑦ 引擎内嵌 S3 客户端**

```sql
WITH S3 ("endpoint" = "http://minio:9000", "use_path_style" = "true", ...)
```

- 下载方是 **Doris BE / Flink TaskManager 容器**，endpoint 必须 minio:9000；写 localhost 会连到容器自己。
- 本机 curl 通不算数，必须从容器内部验证。
- 完整 SQL 与属性对照。

**⑧ 挂载成本地文件系统**

```bash
rclone mount minio:lakehouse /mnt/lakehouse --vfs-cache-mode writes
s3fs lakehouse /mnt/lakehouse -o url=http://localhost:9000 -o use_path_request_style -o passwd_file=$HOME/.passwd-s3fs
```

- 让只认本地路径的老程序无改动地读写对象；-o use_path_request_style 是 path-style 开关。
- **本环境不推荐**：macOS 需 macFUSE + 内核扩展授权；对象的「目录」是伪装的，随机写 / rename / 原子性和真文件系统不同。

**+ 免凭据访问模式**

```bash
mc anonymous set download lake/lakehouse/ods/public/        # 前缀公开读
mc share download --expire=2h lake/lakehouse/ods/a.csv      # 预签名 URL
aws --endpoint-url http://localhost:9000 s3 presign s3://lakehouse/ods/a.csv --expires-in 7200
```

- 预签名把签名编进 query string，拿到的人无需 AK/SK、到期自动失效。
- 这是**访问模式**而非独立客户端，①~⑧ 都能配合。

### 0.3 三条铁律

1. **9000 = S3 API，9001 = Console**：任何程序配置只能填 9000。
2. **视角决定 endpoint**：宿主机用 http://localhost:9000，容器 / 引擎用 http://minio:9000。
3. **一律 path-style**：单机 MinIO 只有一个主机名，virtual-host 风格会拼出 lakehouse.minio:9000，DNS 解析不到。各工具参数名对照：

| 工具 | path-style 参数 |
| --- | --- |
| mc | 自动，无需设置 |
| aws cli | aws configure set default.s3.addressing_style path |
| boto3 | Config(s3={"addressing_style": "path"}) |
| s3cmd | host_bucket = localhost:9000/%(bucket) |
| rclone | provider = Minio（自动） |
| Doris S3 Load | "use_path_style" = "true" |
| Flink / Paimon | s3.path.style.access = true |
| Spark S3A | fs.s3a.path.style.access = true |
| s3fs | -o use_path_request_style |

### 0.4 怎么选

| 你的情况 | 用哪种 |
| --- | --- |
| 只想看看桶里有没有文件 | ① Web Console（零安装） |
| 日常上传 / 列桶 / 写脚本 | ② 宿主机 mc（本机 brew 可用，最稳） |
| 要验证「容器内能不能访问 MinIO」 | ③ Docker mc 容器（需自备镜像），或 安装教程.md 第 4 步的 busybox |
| 已有 aws cli / rclone 工作流 | ④ 通用 S3 CLI |
| 程序里读写对象 | ⑤ SDK |
| 只查服务是否健康 | ⑥ curl /minio/health/live |
| Doris Load / Flink 写湖 | ⑦ 引擎内嵌，endpoint 必须 minio:9000 |
| 临时对外发一个文件 | + 预签名 URL |

## 2. mc 命令行（最推荐）

### 2.1 宿主 mc

> **重要**：Docker Hub 上的 minio/mc 已于 2026-09-11 被官方移除，本机又无该镜像缓存，所以**不要再尝试 docker run minio/mc:...**。直接在 macOS 装客户端，绕开镜像源与代理：

```bash
brew install minio/stable/mc
mc --version

set -a; . /Users/wenhuadong/docker/object-storage/minio/.env; set +a
mc alias set lake http://localhost:9000 "$MINIO_AK" "$MINIO_SK"
mc ls lake
mc ls lake/lakehouse
```

| 片段 | 解释 |
| --- | --- |
| brew install minio/stable/mc | 官方 tap，arm64 原生；不走 Docker、不受镜像源与代理影响 |
| set -a; . .env; set +a | 把 .env 的键导出为环境变量，真值不进命令行历史 |
| mc alias set &lt;别名&gt; <endpoint> &lt;AK&gt; &lt;SK&gt; | 别名写入 ~/.mc/config.json，之后 lake/lakehouse 即代表该桶 |
| http://localhost:9000 | **宿主机视角**；容器内才用 http://minio:9000 |

### 2.2 Docker mc

仅当本机确实已有一个 mc 镜像时可用；好处是能顺带验证跨容器 DNS。把 MC_IMAGE 换成 docker images | grep mc 查到的实际镜像名：

```bash
MC_IMAGE=your-registry/minio-mc:your-tag
docker image inspect "$MC_IMAGE" >/dev/null || { echo "镜像不存在，改用 2.1 宿主机 mc"; exit 1; }

docker run --rm -it \
  --network whd-net \
  -v /Users/wenhuadong/docker/object-storage/minio/.env:/tmp/minio.env:ro \
  --entrypoint /bin/sh \
  "$MC_IMAGE" -c '
    set -a; . /tmp/minio.env; set +a
    mc alias set lake http://minio:9000 "$MINIO_AK" "$MINIO_SK" &&
    mc ls lake &&
    mc ls lake/lakehouse
  '
```

建好别名后，常用操作：

| 操作 | 命令 |
| --- | --- |
| 建桶 | mc mb --ignore-existing lake/lakehouse |
| 上传单文件 | mc cp /path/a.csv lake/lakehouse/ods/user_profile/a.csv |
| 上传整个目录 | mc cp --recursive /path/out/ lake/lakehouse/ods/user_profile/ |
| 下载 | mc cp lake/lakehouse/ods/user_profile/a.csv /tmp/a.csv |
| 列出 | mc ls --recursive lake/lakehouse/ods/ |
| 删除对象 | mc rm lake/lakehouse/ods/user_profile/a.csv |
| 同步目录 | mc mirror /local/dir lake/lakehouse/ods/x/ |
| 看占用 | mc du lake/lakehouse |
| 关匿名访问 | mc anonymous set none lake/lakehouse |
| 开前缀公开读 | mc anonymous set download lake/lakehouse/ods/public/ |

> 两种方式的差别只在 **endpoint** 与**凭据来源**：宿主机 mc 用 localhost:9000 + 宿主 .env；容器 mc 用 minio:9000 + 挂载进去的 .env。注意 -c 脚本跑在容器内部，宿主环境变量不会自动继承，所以 2.2 必须 -v ...:/tmp/minio.env:ro 再 set -a; . /tmp/minio.env; set +a，mc 才拿得到 $MINIO_AK / $MINIO_SK。若不想挂文件，也可把变量换成真值字符串（仅本机临时用）。

## 3. 用通用 S3 客户端

MinIO 兼容 S3 API，任何 S3 工具都能用，关键是把 endpoint 指向 S3 API 端口（9001 是 Console，不行）并开启 path-style。**从宿主机发起就用 http://localhost:9000；从容器内发起才用 http://minio:9000**（下面 3.1~3.3 都是宿主机视角）。

### 3.1 AWS CLI

先按 0.2 的统一前置加载 .env，再配置：

```bash
aws configure set aws_access_key_id "$MINIO_AK"
aws configure set aws_secret_access_key "$MINIO_SK"
aws configure set default.region us-east-1
aws configure set default.s3.addressing_style path

AWS_EC2_METADATA_DISABLED=true \
  aws --endpoint-url http://localhost:9000 s3 ls s3://lakehouse
AWS_EC2_METADATA_DISABLED=true \
  aws --endpoint-url http://localhost:9000 s3 cp /tmp/a.csv s3://lakehouse/ods/user_profile/a.csv
```

| 片段 | 解释 |
| --- | --- |
| aws configure set ... | 写入 ~/.aws/credentials / ~/.aws/config；用 $MINIO_AK 变量，真值不进命令行 |
| default.region us-east-1 | SigV4 签名必须有 region，MinIO 不校验具体值 |
| default.s3.addressing_style path | **强制 path-style**；不加会拼出 lakehouse.localhost 报 bucket does not exist |
| --endpoint-url | 把默认 AWS 端点改指 MinIO，每次都要带 |
| AWS_EC2_METADATA_DISABLED=true | 连非 AWS 端点时跳过 IMDS 凭据探测（否则尝试 169.254.169.254 会卡住） |

### 3.2 Python

```python
import boto3
from botocore.config import Config

s3 = boto3.client(
    "s3",
    endpoint_url="http://localhost:9000",
    aws_access_key_id="<MINIO_AK>",       # 换成真值，或从环境变量读
    aws_secret_access_key="<MINIO_SK>",
    region_name="us-east-1",
    config=Config(s3={"addressing_style": "path"}),
)
s3.upload_file("/tmp/a.csv", "lakehouse", "ods/user_profile/a.csv")
print(s3.list_objects_v2(Bucket="lakehouse", Prefix="ods/user_profile/"))
```

| 片段 | 解释 |
| --- | --- |
| endpoint_url / region_name | 改指 MinIO；region 只为满足 SigV4，MinIO 不校验 |
| Config(s3={"addressing_style": "path"}) | **必加**，否则报 EndpointConnectionError |
| Prefix | S3 没有真目录，ods/user_profile/ 只是对象键前缀 |

官方 SDK 亦可：pip install minio → Minio("localhost:9000", access_key=..., secret_key=..., secure=False)。

## 4. AK 管理

- **根凭据**（MINIO_AK/MINIO_SK）：权限最大，适合本机 / 手动操作，先跑通用它。
- **专用 Access Key**：Console 左侧 **Access Keys → Create access key**，可单独吊销、限制用途；多项目 / 多人接入时优先用专用 key，别到处散 root 凭据。
- 轮换：删掉旧 key 即可，不影响数据；换完后更新各组件配置里的 AK/SK。
- 安全红线：凭据只在 minio/.env 与本机，不写进任何 .md、日志、截图、git。

## 6. 与本机组件对接

本机 MinIO 是 whd-net 上的 minio:9000，Doris BE / Flink / DS 都接它。

### 6.1 S3 Load

Doris 用 WITH S3(...) 读对象，关键是内网 endpoint + path-style：

```sql
LOAD LABEL game_db.imp_user_profile (
  DATA INFILE("s3://lakehouse/ods/user_profile/*")
  INTO TABLE ods_user_profile
  COLUMNS TERMINATED BY ","
)
WITH S3 (
  "endpoint" = "http://minio:9000",
  "access_key" = "<MINIO_AK>",
  "secret_key" = "<MINIO_SK>",
  "bucket" = "lakehouse",
  "use_path_style" = "true"
);
```

要点：

- endpoint 用 http://minio:9000（容器视角），**不是** localhost、不是 9001。
- use_path_style = "true"；Paimon Catalog 里对应属性名是 s3.path.style.access，两者不同、别混。
- 下载方是 **BE 容器**，连通性必须按 安装教程.md 第 4 步从 BE 视角验证（本机 curl 通不算数）。
- 上面及 6.2 里的 &lt;MINIO_AK&gt; / &lt;MINIO_SK&gt; 都是**占位符**，执行前换成 .env 里的真值，别把尖括号一起复制（在 shell 里会被当成输入重定向）。

### 6.2 写 Paimon

Flink 把 MinIO 当 S3 文件系统，warehouse 指向 s3://lakehouse/paimon/，同样要 path-style：

```
s3.endpoint = http://minio:9000
s3.access-key = <MINIO_AK>
s3.secret-key = <MINIO_SK>
s3.path.style.access = true
```

### 6.3 通用前缀约定

| 用途 | 桶 / 前缀 |
| --- | --- |
| 画像数据 | s3://lakehouse/ods/user_profile/ |
| 事件数据 | s3://lakehouse/ods/user_event/ |
| Paimon warehouse | s3://lakehouse/paimon/ |

## 7. 停止备份

```bash
docker stop minio && docker start minio          # 首选：数据、凭据全保留
docker rm -f minio                               # 删容器，数据卷还在（bind mount）
rm -rf /Users/wenhuadong/docker/object-storage/minio/data/*     # 仅此命令清空数据
```

| 动作 | 数据安全 |
| --- | --- |
| stop / start | 全保留 |
| docker rm -f minio | minio/data 是 bind mount，保留 |
| rm -rf .../data/* | 只有显式执行才清，含 paimon/ warehouse |

备份 = 直接拷 minio/data/ 目录；恢复 = 拷回去再 docker start minio。

## 8. 排错速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 把 9001 写进 s3.endpoint | Console 口不是 S3 API | 改 9000 |
| UnknownHost: minio / 本机通容器内不通 | endpoint 写了 localhost，或 BE 没接 whd-net | endpoint 改 http://minio:9000；BE 接入共享网络 |
| bucket does not exist（mc 能连，Doris 报） | 桶名 / 前缀写错 | mc ls lake 核对 |
| SignatureDoesNotMatch / AccessDenied | AK/SK 错、含 $/! 未转义、时间差大 | 核对凭据；shell 单引号包住；查本机时间同步 |
| The request signature ... 但密钥没错 | 走成 virtual-host 风格 | Doris 加 use_path_style=true；Flink 加 s3.path.style.access=true |
| 表头被当脏数据 | CSV 带表头 | 造数默认不带表头 |
| Console 菜单找不到 | 新版精简功能 | 用 mc 等价命令 |
