# MinerU 安装教程

> **一句话结论**：用 uv 建 Python 3.12 虚拟环境，装 mineru 4.x，完成 HTML 冒烟转换，再验 PDF 转换与 WebUI。系统 Python 3.10 不参与。

> **本文解决什么**：本机没有 MinerU，如何装好并确认可用。
>
> **适用谁**：macOS arm64、已装 uv 与 Docker Desktop 的用户。
>
> **读完能做什么**：建独立虚拟环境、装包、验转换、启动 WebUI、处理常见故障。

> **核对时点**：2026-11-19。macOS 27.2.1，arm64，系统 Python 3.10.14，uv 已装。
>
> **本机实测**：uv 路径为 /Users/wenhuadong/.local/bin/uv。whd-net 网络存在。MinerU 尚未安装。可用磁盘 91Gi。

---

## 一、安装前复核

```bash
command -v uv && uv --version

python3 --version

lsof -nP -iTCP:7860 -sTCP:LISTEN || echo '7860 空闲'

ls -ld /Users/wenhuadong/docker/ai/mineru
```

| 检查项 | 期望 | 不满足时 |
| --- | --- | --- |
| uv | 已安装，输出版本号 | 执行 curl -LsSf https://astral.sh/uv/install.sh \| sh 安装 |
| 系统 Python | 3.10.14，不用于安装 | 保持原样，由 uv 另建 3.12 |
| 7860 端口 | 空闲或仅旧 MinerU 占用 | 停旧进程后复查 |
| mineru 目录 | 存在且当前用户可写 | 用 mkdir -p 创建 |

> **注意**：系统 Python 是 3.10.14，低于 MinerU 要求的 3.11。不要在它上面直接装包。uv 会下载 Python 3.12 并建立隔离虚拟环境，系统 Python 不变。

---

## 二、创建虚拟环境

```bash
cd /Users/wenhuadong/docker/ai/mineru

uv venv .mineru --python 3.12

source .mineru/bin/activate

python --version
```

预期输出：python --version 显示 Python 3.12.x。

| 参数 | 作用 |
| --- | --- |
| .mineru | 虚拟环境目录，建在组件目录下 |
| --python 3.12 | 指定版本，uv 自动下载缺失解释器 |
| source | 激活虚拟环境，后续命令走该环境 |

> 虚拟环境放在组件目录内，删除目录即整体清理。它不写系统站点包，也不影响 pyenv 下的 3.10.14。

---

## 三、安装 MinerU

```bash
uv pip install -U "mineru>=4.0,<5"

mineru --help

command -v mineru-kit
```

预期输出：mineru --help 打印命令列表。command -v mineru-kit 打印虚拟环境内的可执行文件路径。

| 命令 | 作用 |
| --- | --- |
| uv pip install -U | 在已激活虚拟环境安装或升级到 4.x 最新版 |
| mineru>=4.0,&lt;5 | 锁定 4.x 大版本，避开 3.x 旧命令行 |
| mineru --help | 确认主命令可用 |
| command -v mineru-kit | 确认转换命令可用 |

> 基础包已含 WebUI、轻量模型运行时与本地视觉语言模型。苹果芯片的 Torch 依赖自动加入，无需单独装显卡版本。需要更高吞吐的服务端引擎时，再装 torch 或 full 扩展。扩展只用 4.x 的 torch 与 full，不用 3.x 的扩展名。

---

## 四、冒烟验证

**前提**：虚拟环境已激活，mineru-kit 可用。

```bash
cd /Users/wenhuadong/docker/ai/mineru

python -c "from pathlib import Path; Path('report.html').write_text('<h1>MinerU</h1><p>First conversion.</p>', encoding='utf-8')"

mineru-kit parse report.html -o report.md --tier flash

cat report.md
```

预期输出：report.md 含标题 MinerU 与正文 First conversion.

| 参数 | 作用 |
| --- | --- |
| parse | 无状态转换子命令 |
| report.html | 输入文件，原生网页格式 |
| -o report.md | 输出文件路径 |
| --tier flash | 最快档位，网页解析不下载模型 |

> 这一步不下载模型。它只验证包、命令行与文件读写链路。模型下载留到 PDF 转换步骤。

---

## 五、转换 PDF

**前提**：把待转换的 PDF 放到组件目录，命名为 sample.pdf。

```bash
mineru-kit parse sample.pdf -o sample.md --tier flash --ocr-mode txt

mineru-kit parse sample_data/GBT+48000.3-2026.pdf -o sample_data/GBT+48000.3-2026.md --tier flash --ocr-mode txt
```

预期输出：同目录生成 sample.md，含文档正文。

| 参数 | 作用 |
| --- | --- |
| --ocr-mode txt | 只读 PDF 文本层，不下载推理模型 |
| --tier flash | 快速档位，配合文本层读取 |
| --ocr-mode ocr | 扫描件用此值，需先下载模型 |

> 首次做模型支撑的转换会下载权重。文本层读取不触发下载。扫描版 PDF 没有文本层，要把 --ocr-mode 改成 ocr，并先执行 mineru-kit models download --tier standard。

## 六、启动 WebUI

**提示**：监听 0.0.0.0 会把服务暴露到局域网。仅在可信网络使用。需要限制访问时改成 127.0.0.1。

```bash
mineru-kit webui --server-name 0.0.0.0 --server-port 7860
```

预期输出：终端打印本地地址。浏览器打开 http://localhost:7860 看到上传界面。

| 参数 | 作用 |
| --- | --- |
| --server-name 0.0.0.0 | 监听所有地址，容器内调用需要 |
| --server-port 7860 | 固定端口，与复核步骤一致 |

---

## 七、容器部署

**说明**：本节只用于 Linux 加英伟达显卡的服务器。本机是苹果芯片，不执行本节命令。

官方容器流程面向 Linux 加英伟达显卡。苹果芯片走容器拿不到显卡加速，所以本机走本机虚拟环境方案。服务器环境按下面两条命令起服务。

```bash
git clone https://github.com/opendatalab/MinerU.git
cd MinerU

docker build -t mineru:4 -f docker/global/Dockerfile .
```

```bash
本组件在 whd-net 的静态地址为 172.30.0.18。compose 内各服务按静态段从 .18 起顺延取号。重建容器须保留原 IP。依据：code-wiki/06 的 IP 分配表。

docker compose -f docker/compose.yaml --profile webui up -d

docker compose -f docker/compose.yaml --profile api up -d
```

| Profile | 端口 | 用途 |
| --- | --- | --- |
| webui | 7860 | 文档上传界面 |
| api | 8000 | 文档转换接口 |
| router | 8002 | 多服务多显卡入口 |
| openai-server | 30000 | 视觉语言模型推理，不是转换接口 |

> 镜像安装的是 mineru[torch] 4.x 范围版本，同一标签重建不保证固定小版本。要锁定版本，把 Dockerfile 里的范围改成精确版本再重建。

## 八、停止与重来

```bash
# 停 WebUI：在运行 WebUI 的终端按 Ctrl+C

deactivate

cd /Users/wenhuadong/docker/ai/mineru
rm -rf .mineru
uv venv .mineru --python 3.12
source .mineru/bin/activate
uv pip install -U "mineru>=4.0,<5"
```

| 动作 | 数据影响 |
| --- | --- |
| 按 Ctrl+C | 只停 WebUI，虚拟环境保留 |
| deactivate | 退出虚拟环境，文件保留 |
| rm -rf .mineru | 删除虚拟环境与已装包 |
| 保留 report.html 与 report.md | 输入与输出文件不受影响 |

> report.html 与 sample.pdf 放在组件目录，不在虚拟环境内。删除 .mineru 不会删掉它们。

## 十、故障速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 装包报 Python 版本不符 | 用了系统 3.10 | 激活 .mineru 后再装 |
| uv venv 报找不到 3.12 | uv 未下载解释器 | 执行 uv python install 3.12 后重试 |
| mineru-kit 命令找不到 | 虚拟环境未激活 | source .mineru/bin/activate |
| 7860 被占 | 旧进程在跑 | lsof 查进程后停掉 |
| 网页转换无输出 | 文件名或路径写错 | ls 核对 report.html |
| PDF 报缺模型 | 用了 ocr 模式未下载 | 执行 mineru-kit models download --tier standard |
| WebUI 页面打不开 | 只监听了 127.0.0.1 | 用 0.0.0.0 启动 |

## 十一、小结

1. 本机安装走 uv 建 3.12 虚拟环境，系统 Python 3.10 不参与。
2. 基础包含 WebUI 与轻量模型，苹果芯片自动带 Torch。
3. 网页与 PDF 文本层读取不下载模型，扫描件要先下模型。
4. 容器方案只用于 Linux 加英伟达显卡的服务器。
5. 验收六条：解释器版本、两个命令、网页输出、PDF 输出、WebUI 页面。
